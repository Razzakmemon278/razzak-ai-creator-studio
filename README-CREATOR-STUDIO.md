# Razzak AI Creator Studio — Starter v1

A mobile-first, free-first browser workspace for:
- **AI tools:** structured prompt builder
- **Social:** caption, hashtag, and CTA drafts for TikTok, Instagram Reels, YouTube Shorts, Pinterest, and Facebook
- **Video:** scene-by-scene short-form storyboard planner (30–120 seconds)

## Safety and scope
- This starter runs in the browser and does not require an API key.
- It does not upload drafts, edit account profiles, publish posts, or call paid AI services.
- Generated text is a template-based first draft, not a connected AI model. Verify facts, claims, rights, and platform rules before use.
- No existing files were replaced. The setup was added on branch `setup/creator-studio-v1`.

## Preview on Android
Open `index.html` in a browser after downloading the branch, or enable GitHub Pages for this branch through repository Settings → Pages if available. For a public static site, publish the three app files (`index.html`, `styles.css`, `app.js`) using GitHub Pages.
