# Free-First Mobile Creator Toolkit

Check current free-tier limits, watermark rules, export quality, regional availability and privacy terms before relying on any service; free plans change.

- **YouTube Create / YouTube Studio:** editing (availability varies) and channel upload/analytics.
- **VN Video Editor:** mobile editing option; check current export and watermark behavior in-app.
- **CapCut:** mobile editing and captions; some features/assets may be paid or region-limited.
- **Canva Free:** layouts, covers and social graphics; premium assets are not free.
- **GitHub Pages + GitHub Actions:** host the static Creator Studio and run repository workflows; Pages settings and successful Actions deployment are required.
- **Hugging Face Spaces / open-source models:** useful for experiments, but hosted demos may sleep, queue, or have usage limits. Local mobile execution can be resource-heavy.
- **ChatGPT / Gemini free tiers:** use for brainstorming and drafts within their current limits; don't assume unlimited image/video generation.

## Privacy and safety
- Never commit API keys, passwords, session cookies or private account data to GitHub.
- Avoid uploading private face photos or personal files to third-party services without reviewing their data terms.
- Keep final social publishing manual and approval-based.
- Prefer original characters, properly licensed assets and platform-compliant music.
