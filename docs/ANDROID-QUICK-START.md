# Android Quick Start — Razzak AI Creator Studio

This project is designed to be used from an Android phone. It does not need Termux, a paid API key, or an npm install for ordinary use.

## 1. Open the dashboard

Repository: https://github.com/Razzakmemon278/razzak-ai-creator-studio

The current website files are index.html, styles.css and app.js. The browser tools make local template-based drafts; they do not call a live AI model or render a video file.

To open the site online, check the repository's Actions page first:
https://github.com/Razzakmemon278/razzak-ai-creator-studio/actions

If the Pages workflow succeeds, use the published URL shown in the completed deployment run. The expected GitHub Pages URL pattern is:

https://razzakmemon278.github.io/razzak-ai-creator-studio/

That URL was not confirmed live during this audit. If no published URL appears, open repository Settings → Pages and select GitHub Actions as the build/deployment source, then follow the Pages workflow result. The quality-pack branch must be reviewed and merged before its new files become part of the main site.

## 2. Use the dashboard

1. Open the dashboard in Chrome.
2. Choose Prompt Builder to draft a detailed prompt for an original idea.
3. Choose Social Captions to prepare a hook, caption, CTA and hashtags. Review hashtags, links and claims before use.
4. Choose Video Planner and select a target length from 30 to 120 seconds.
5. Choose Weekly Schedule to make a draft plan.
6. Use the Copy buttons to transfer text into an editing app or notes app.

These tools are templates. A generated caption, storyboard or prompt is not proof that the media itself has been generated.

## 3. Find mobile tools

Open the new tool directory at the site root as tools.html after this branch has been reviewed and merged. It lists official links for image/planning, editing, voice and manual publishing, with caveats about free-tier limits.

Start with free options. Before committing to an entire 2-minute video, create and export a single 5-second test clip. Check for watermarks, audio quality, resolution and whether the tool is available in Pakistan. Do not assume AI-video credits are unlimited.

## 4. Daily creator workflow

- Cartoon channel: use the Pip red-panda production plan in content/pip-red-panda-episode-2-minute.md. Fifteen 8-second scenes make a 120-second target; keep Pip's design constant between scenes.
- Islamic channel: use only a verified, permitted recording from a named reciter and check the Arabic against a trusted mushaf. Do not synthesize or imitate Qur'anic recitation.
- Fictional AI-vlog channel: use a fictional character, not the creator's face, unless the owner later explicitly changes that rule.
- Pinterest affiliate content: verify the current product facts and destination URL, and include clear affiliate disclosure.

## 5. Export and publish

Before exporting, check the full video, voiceover, captions, music rights, framing, final frame, watermark and destination link. Keep the finished MP4 and caption package in a clearly named folder on the phone.

Posting remains manual. No profile change, social login, paid generation or public post is performed by this repository setup. Publish only after the owner reviews and approves the exact final asset and caption.

## 6. If something fails

- A blank or missing site: inspect the Pages workflow in Actions and the deployment URL from its successful run.
- Buttons do nothing: refresh the page in Chrome, then check the repository Actions quality-check result after the branch/PR runs.
- Copy button does not copy: tap inside the output text, select it, and choose Copy from the Android menu.
- A tool asks for a card or payment: skip it. No paid trial is required by this project.
