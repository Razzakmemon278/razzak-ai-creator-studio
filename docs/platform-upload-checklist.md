# Platform Upload Checklist

This checklist is for manual, user-approved publishing. No platform has been logged into or posted to by this file.

## YouTube Shorts
- Export: vertical 9:16 MP4, ideally 1080×1920; verify platform limits at upload time.
- Add a clear title, short description, and relevant hashtags.
- Preview the thumbnail/frame and captions before publishing.
- Upload from YouTube Studio or the YouTube Android app; select public only after final review.

## TikTok
- Upload the final MP4 in the TikTok app.
- Review caption, cover, sound rights, audience and visibility.
- Do not use copyrighted music unless licensed for the intended use.
- Publish only after explicit approval.

## Instagram Reels
- Upload through Instagram; review crop, cover, caption, alt text where available, and audience.
- Confirm account type and any branded-content disclosure if applicable.
- Publish only after explicit approval.

## Pinterest
- Create a vertical Pin with a clear title, useful description and destination URL.
- For affiliate content, clearly disclose the affiliate relationship in the Pin description and comply with the current Pinterest and affiliate-program rules.
- Confirm the destination link works and matches the promoted product.
- Publish only after explicit approval.

## Not possible from repository access alone
- I cannot safely sign in to your social accounts, verify the actual account identity, or upload/publish media without the relevant platform workflow and your explicit approval.
- The repository contains a workflow/site starter; it does not itself render a finished MP4 or grant social platform upload permissions.
- GitHub Pages must be enabled/configured in repository settings and the deployment workflow must complete successfully before a live website URL can be confirmed.
